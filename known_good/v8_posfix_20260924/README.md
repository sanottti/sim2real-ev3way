# v8 (位置ドリフト対策あり、学習途中で打ち切り) — 実機投入版

> **【2026-09-29 訂正】** このバージョンを作った動機である「位置ドリフト」
> 診断は、実機ログの`gyro_ang_x10`(度×10と誤読、実際はラジアン×10)の
> 単位誤読に基づいていた可能性が高い。実際は毎回転倒直前(40°前後)まで
> 傾いていたと判明しており、「傾き制御は完璧・位置ドリフトのみが課題」
> という前提自体が誤り。POS_LIMIT_RAD・位置/速度ペナルティ強化は存在しない
> 問題への対策だった疑いがある。詳細は`SETUP_NOTES.md`の該当訂正セクション参照。

2026-09-24 取得。v6実機ログ解析で判明した「位置ドリフト」問題への対処として
報酬設計を見直し、v7から再学習した結果。**200世代の学習は完走していない**
(gen135で打ち切り)。

## 学習条件
- v7(COM位置ランダム化版、best_reward=1325.2)から再開
- 位置ペナルティ強化: 0.015→0.05、速度ペナルティ強化: 0.008→0.02
- 新規: `POS_LIMIT_RAD=5.0`(車輪回転量、片輪あたり)超過でエピソードを
  転倒と同格の失敗として打ち切る条件を追加
- popsize=200, generations=200(上限)で開始したが、gen27でbest_reward=1170.0
  に達した後gen135まで108世代横ばいが続いたため、ユーザー指示でgen135
  (経過496分)で打ち切り

## Sim上の結果
- best_reward = 1170.0
- 通常条件: 3本中2本が30秒完走(位置ドリフト最大1.9〜3.1rad、上限5.0radの
  範囲内)、1本は0.7秒でPOS_LIMIT_RAD超過により打ち切り(傾き自体は3.4°で
  正常 = 位置ドリフト終了条件が意図通り機能していることを確認)
- 複合最悪条件: 0.3秒で転倒(傾き31.9°が原因、位置ドリフトではない)

## 採用に関する注意
学習が横ばいのため、v7からの明確な性能向上はSim上では確認できていない。
POS_LIMIT_RAD超過による早期終了ロジックが正しく機能することは確認できたが、
それによって「位置ドリフトを避けつつバランスも保つ」解に収束しきったとは
言えない状態。**実機での検証が必要**。
