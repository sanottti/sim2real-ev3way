# v15 実機ログ解析(2026-10-01取得、5本)

Phase 4 Stage2(忠実化Sim + オモリ玉で2段階学習)の重みを実機投入した
初めてのテスト。CSVヘッダーに`# nn_weights_version=v15`が明記されており
バージョンは確実。

★ `gyro_ang_x10` は**ラジアン×10**(度×10ではない)。以下の角度はすべて
この前提で換算済み。

## v7(2026-09-29、9本)との比較 — v15は実機で明確に悪化

| 指標 | v7(9本) | **v15(5本)** |
|---|---|---|
| 平均生存時間 | **2.27s** | 1.49s(34%悪化) |
| PWM飽和率(\|pwm\|≥95) | **2.0%** | **41.1%(20倍)** |
| \|PWM\|平均 | **30.9** | **60.1(2倍)** |
| PWM符号反転 | 4.7回/秒 | 4.4回/秒(同等) |

**v15は常にモータを全力で叩く「bang-bang制御」になっており、v7の穏やかな
制御と対照的**。実機のモータは飽和時に逆起電力・電流制限で実際のトルクが
出ないため、この制御スタイルは実機で裏目に出たと考えられる。

## ★重要: Phase 2の忠実化は正しく機能していた

Sim(fidelity-all、10シード)での同じ指標を実測と突き合わせると:

| | Sim予測 飽和率 | 実機実測 飽和率 |
|---|---|---|
| v7 | 7.5% | 2.0% |
| **v15** | **38.2%** | **41.1%** |

**Simはv15の「高飽和・攻撃的な制御スタイル」を正確に予測できていた**
(38.2% vs 41.1%)。つまりPhase 2の忠実化(出力経路・モータ速度飽和等)は
狙い通り機能しており、Simは制御の「質」を正しく再現している。

ただし**生存時間の絶対値は依然として乖離**(Sim 6.32s vs 実機 1.49s、約4倍)。
残るギャップの最有力候補は**モータの実トルク特性**:
Simの`eff_torque*(pwm - ω/max_speed)`という線形逆起電力モデルは、
低速時にPWM100%で最大トルクを出せる前提だが、実機のEV3モータは
電流制限・H-bridge抵抗により、特に飽和付近で想定よりトルクが出ない可能性が高い。

## ★朗報: v16(Stage3、押し外乱学習済み)は制御スタイルが大きく改善

既に実機投入済みのv16をSim上で同じ指標で測ると:

| | Sim飽和率 | Sim \|PWM\|平均 |
|---|---|---|
| v7 | 7.5% | 50.9 |
| v15 | 38.2% | 47.7 |
| **v16** | **2.2%** | **9.2** |

**v16は押し外乱への耐性を学習した結果、はるかに穏やかで飽和しない制御を
獲得している**(v7の実機成功パターン=低飽和率に近い)。実機で成功した
v7の特徴(飽和率2.0%)と一致しており、**v16は実機でv15より良い結果を
出す可能性が高い**。

## わかったこと

- **Sim上の生存時間だけで実機性能を判断してはいけない**。v15はSimでv7を
  大きく上回ったが(18.16s vs 11.16s)、実機では逆に悪化した(1.49s vs 2.27s)
- **PWM飽和率が実機性能の良い予測指標になりうる**。実機で最も長く立った
  v7は飽和率2.0%、最も早く倒れたv15は41.1%。飽和は「モータの性能限界を
  超えた指令」を意味し、実機ではトルクが出ないため制御が破綻する
- Phase 2の忠実化により**Simは制御スタイル(飽和率)を正確に予測できる
  ようになった**。これは大きな前進であり、今後は「Simの生存時間」ではなく
  「Simが予測する飽和率・制御の穏やかさ」も採用判断の指標に加えるべき

## 次にやること
